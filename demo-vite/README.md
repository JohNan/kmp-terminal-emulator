# KMP Wasm Terminal - Vite TypeScript Demo

This folder contains a modern TypeScript single-page application built with Vite that integrates the pre-compiled Kotlin Multiplatform WebAssembly terminal emulator.

## Running the Demo

1. Install the dependencies:
   ```bash
   npm install
   ```

2. Start the Vite development server:
   ```bash
   npm run dev
   ```

3. Open the URL printed in the terminal (usually `http://localhost:5173`).

---

## Production Build

To compile and optimize the web application:
```bash
npm run build
```
The output files will be built into the `dist/` directory, ready for deployment.
